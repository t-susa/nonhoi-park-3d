# のんほいパーク 3D バーチャル散策ワールド 🦒🎡🦕🌴
（豊橋総合動植物公園 3D Webツアー）

愛知県豊橋市にある「のんほいパーク（豊橋総合動植物公園）」をWebブラウザ上で自由に散策できる本格的な3Dバーチャルパークです。実在のOpenStreetMap（OSM）およびPLATEAUの地理座標データに基づいてパーク全体を忠実に再現し、PC・スマートフォンの両方で軽快に動作します。

---

## 🌟 主な機能と見どころ

### 1. 実在の地理・地形・位置関係の正確化（OpenStreetMap / PLATEAU 準拠）
- **正確な公園境界・水域・道路網**:
  - 実測座標（北緯34.720, 東経137.432）に基づき、148頂点の外周境界、全278本の舗装路・小道、9つの池・水域を正確に配置。
- **実在する128棟の建築物を実寸3D立体化**:
  - 豊橋市自然史博物館、大温室、展望塔、各動物舎、中央門・東門・西門などを正確な位置・フットプリント形状で立体押し出し。

### 2. 建物・3Dオブジェクトの圧倒的ディテール
- **🎡 大観覧車（実寸全高48m・遊園地エリア）**:
  - 実在座標 `[176.5, 99.7]` に配置。Aフレーム鉄骨トラス支柱、二重リング、24基のマルチカラーゴンドラ（パノラマガラス窓・シート付き）。
  - **観覧車搭乗体験**: ゴンドラに乗って地上50mの最高到達点から園内を360度パノラマで見下ろせます！夜間には流れるLEDイルミネーションが点灯。
- **🦕 野外恐竜ランド（自然史博物館前広場）**:
  - 実在座標 `[-89.1, -34.5]` 付近。
  - **実物大ブラキオサウルスの親子**: 親（全長約23m・高さ約13m）の首が呼吸するように動き、足元には親を見上げる子恐竜。
  - **ティラノサウルス (T-Rex)**: 筋肉質な体躯、開閉する鋭い牙の顎、咆哮サウンド。
  - **トリケラトプス、アンキロサウルス、トウジャンゴサウルス、巨大ザメ・メガロドンの顎**モニュメント。
  - ルーブル調の**ガラスピラミッドエントランス**を備えた自然史博物館本館。
- **🦒 アフリカ園・キリンデッキ**:
  - サバンナエリア `[129.2, 44.2]`。地上3.1mの木製展望デッキとバリアフリースロープ。
  - デッキに上がると、**キリンの顔と直接目線が合う**リアルな観察体験。キリンの親子とシマウマ。
- **🌴 大温室 & モネの池（植物園エリア）**:
  - 幾何学トラスガラスドームから内部の熱帯樹木が透けて見える大温室。
  - 睡蓮が浮かぶモネの池と緑の太鼓橋、木造水車。
- **🐻‍❄️ 極地動物館**:
  - 氷山、水中観察プール、ホッキョクグマ、よちよち歩くペンギンたち。
- **🐘 アジアゾウ舎**:
  - 鼻を揺らすアジアゾウの親子。
- **🦁 猛獣舎**:
  - 岩山に佇む百獣の王ライオン。
- **🚂 蒸気機関車 D51 89（デゴイチ）**:
  - 中央門すぐの広場に静態保存されている本物のSLを忠実に再現。
- **🎢 のんほいコースター & 🚌 園内巡回バス**:
  - 赤いループ軌道のコースター。
  - 園内373頂点の周遊ルートを自動でゆっくりと巡回走行するレトロバス。

### 3. 操作感の向上と3つのカメラモード
- **① 一人称散策（FPS）**:
  - `W / A / S / D` または `矢印キー`: 移動
  - `マウスドラッグ`（または画面右側スワイプ）: 視線回転
  - `Space`: ジャンプ
  - `Shift`: ダッシュ
  - `E`: 近くのスポット詳細ガイド表示
- **② 三人称視点（TPS）**:
  - 探検家風アバターを背後から追従。
- **③ ドローン全景マップ俯瞰モード**:
  - 上空約220mからパーク全体を見渡す鳥瞰ビュー。
  - 地面の任意の場所をクリック・タップするだけでその場所へ移動可能！
- **🗺️ レーダーミニマップ＆ファストトラベル**:
  - 画面右上の実寸マップをタップするだけで瞬時にワープ。
  - 画面下部のファストトラベルバーで12箇所の主要スポットへワンクリック移動。
- **☀️ 昼 / 🌇 夕方 / 🌃 夜 時間帯切替**:
  - 昼の青空と漂う積雲、夕日の黄金グレア、夜の星空とイルミネーション点灯（UnrealBloomPass による美しい光輪）。
- **📷 写真撮影モード**:
  - 園内のベストアングルを高画質PNG画像としてワンクリック保存。

## 🔒 限定公開（閲覧制限）の仕組み

1. **検索エンジンの完全除外（noindex / nofollow）**:
   - `robots.txt` および `<meta name="robots" content="noindex, nofollow, noarchive, nosnippet">` により、検索エンジンには登録されません。
2. **入園ゲート（合言葉・パスコード認証）**:
   - 初期合言葉: `nonhoi` または `のんほい`（SHA-256暗号化照合）。
3. **ワンクリック招待リンク**:
   - `#token=nh-guest-2025` 付きURLにより、合言葉入力なしで1タップでそのまま入園可能。
4. **ランダムファイル名・シークレットパス**:
   - `nh-k7v9m2x4.html` や `v-secret-8a2f/` など、推測不可能なURLでアクセス可能。
