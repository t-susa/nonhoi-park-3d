# のんほいパーク 3D バーチャル散策ワールド 🦒🎡🦕🌴
（豊橋総合動植物公園 3D Webツアー）

愛知県豊橋市にある「のんほいパーク（豊橋総合動植物公園）」をWebブラウザ上で自由に3D散策できるバーチャルパークです。PC・スマートフォンの両方に対応し、軽量・高速なThree.jsで動作します。

---

## 🌟 主な機能・見どころ

### 1. 4大ゾーン＆ランドマークの完全再現
- **🎡 遊園地エリア**:
  - 実物大の大観覧車がゆっくり回転。
  - **観覧車搭乗体験**: ゴンドラに乗って地上50mの最高到達点から園内を一望可能！
  - 夜間にはイルミネーションが点灯。
- **🦕 自然史博物館＆野外恐竜ランド**:
  - 体長約20m超の巨大ブラキオサウルス（首が動きます）、ティラノサウルス、トリケラトプス。
  - 恐竜の咆哮効果音（Web Audio APIによるシンセシス音源）。
  - ピラミッド型ガラスエントランスの自然史博物館本館。
- **🌴 植物園エリア**:
  - 象徴的な半透明ガラスの大温室（内部の熱帯樹木が透けて見えます）。
  - 色とりどりの花が咲き誇る大花壇。
  - モネの池（すいれんの園）と日本風太鼓橋。
- **🦒 動物園エリア**:
  - アフリカ園：キリンデッキとキリンの親子。
  - 極地動物館：ホッキョクグマとよちよち歩くペンギンたち。
  - アジア園：アジアゾウ舎。
- **🎫 正門＆中央大池**:
  - パークのシンボルゲート。
  - 噴水が吹き上がる大池と朱色の展望橋。

### 2. 操作性と快適性
- **PC操作**:
  - `W / A / S / D` または `矢印キー`: 移動
  - `Shift`: ダッシュ（走る）
  - `Space`: ジャンプ
  - `マウスドラッグ`: 視線回転
  - `V`: 一人称（FPS） / 三人称（TPS）カメラ切替
  - `E`: 近くのスポット詳細解説を開く
- **スマートフォン/タブレット操作**:
  - 画面左下のバーチャルジョイスティックで直感移動
  - 画面スワイプで視線操作
  - ジャンプボタン（🦘）
- **🗺️ レーダーミニマップ＆ファストトラベル**:
  - 右上の園内マップをクリック／タップするだけで、目的のエリアへ瞬時にワープ移動可能！
- **☀️ 昼・🌇 夕方・🌃 夜の環境切替**:
  - 昼のさわやかな青空、夕方のロマンチックな夕景、夜のイルミネーションと星空を楽しめます。
- **📷 写真撮影モード**:
  - 園内のベストショットをワンクリックでPNG画像として保存。
- **🔊 プロシージャル環境音**:
  - 鳥のさえずり、足音、オルゴールベル、恐竜の唸り声をブラウザ単体で生成（ミュート切替対応）。

## 🔒 限定公開（閲覧制限）の仕組み

見る人を限定するため、以下のトリプル保護を採用しています：

1. **検索エンジンの完全除外（noindex / nofollow）**:
   - `robots.txt` および HTML ヘッダーの `noindex, nofollow, noarchive` により、Googleなどの検索エンジンには一切登録されません。
2. **入園ゲート（合言葉・パスコード認証）**:
   - ページアクセス時に入園パスコード（初期合言葉: `nonhoi`）を要求。
   - クライアント側で SHA-256 ハッシュ照合されるため、パスコードを知らない人は3Dシーンに進めません。
3. **ランダムファイル名・シークレットURL**:
   - ランダムファイル名（例: `nh-k7v9m2x4.html`）やシークレットパスを用意。
4. **ワンクリック招待リンク機能**:
   - URLトークン（`#token=nh-guest-2025`）付きの招待URLを使えば、送られた人は合言葉の入力なしでワンクリックで入園できます。

## 🛠️ 開発・ビルド方法

```bash
# 依存関係のインストール
npm install

# ローカル開発サーバー起動
npm run dev

# プロダクションビルド（ランダムファイル名やシークレットパスを自動生成）
npm run build

# ビルド成果物のローカルプレビュー
npm run preview
```
